# Justmine Tea Customer App

Project React + Vite untuk customer app Justmine Tea.

## Setup & Instalasi

1. Install dependencies:
   ```bash
   npm install
   ```

2. Konfigurasi Firebase:
   Buka file `src/api/firebase.js` dan isi dengan konfigurasi Firebase Anda.

3. Jalankan development server:
   ```bash
   npm run dev
   ```
